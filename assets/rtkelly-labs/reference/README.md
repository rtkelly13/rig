# `rtkelly-labs` Reference Materials

This directory preserves the sequence of historical and approved reference images for the `rtkelly-labs` brand identity.

## Manifest Configuration

The active primary reference and sequence metadata are declared machine-readably in [`manifest.json`](./manifest.json).

- **Active Primary Baseline**: `02-smooth-crossover-baseline.jpg`

## Reference Sequence

1. **`01-original-concept.jpg`**:
   - Initial generative Concept 2 ("Isometric Architecture Glyph").
   - Multi-faceted interlocking isometric prism structure in emerald teal and electric cyan.
2. **`02-smooth-crossover-baseline.jpg`** (**PRIMARY**):
   - Approved baseline photo with continuous diagonal crossover beams (eliminates longitudinal dividing seams running down beam faces).
   - Serves as the ground truth calibration target for the vector builder and SVG simplification engine.
3. **`rtkelly-labs.png`**:
   - 1024x1024 lossless raster baseline used for quantitative image drift measurement.
