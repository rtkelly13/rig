# `Parquet.SourceGenerator` Reference Materials

This directory preserves the sequence of historical and approved reference images for the `Parquet.SourceGenerator` brand identity.

## Manifest Configuration

The active primary reference and sequence metadata are declared machine-readably in [`manifest.json`](./manifest.json).

- **Active Primary Baseline**: `02-simplified-cad-baseline.jpg`

## Reference Sequence

1. **`01-original-wood-tile.jpg`**:
   - Initial generative concept featuring parquet floor tile textures, organic wood grain, and git tree forks.
2. **`02-simplified-cad-baseline.jpg`** (**PRIMARY**):
   - Approved simplified CAD baseline regularizing the diamond silhouette and establishing crisp branch vectors.
   - Serves as the ground truth calibration target for the vector builder and SVG simplification engine.
3. **`parquet-diamond.png`**:
   - 1024x1024 lossless raster baseline used for quantitative image drift and calibration testing.
